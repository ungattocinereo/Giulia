# Лендинг Юлии Поповой

Современный одностраничный лендинг для психолога, тьютора и профориентолога Юлии Поповой.

## Технологии

- React 18
- Vite
- Tailwind CSS
- Phosphor Icons

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр production сборки
npm run preview
```

## Структура проекта

- `/src/App.jsx` - Основной компонент со всеми секциями
- `/src/index.css` - Глобальные стили и Tailwind
- `/src/main.jsx` - Точка входа React
- `/index.html` - HTML-шаблон

## Секции лендинга

1. **Header** - Навигация с плавным скроллом
2. **Hero** - Главный экран с CTA кнопками
3. **О себе** - Информация о специалисте
4. **Кому я могу помочь** - Целевая аудитория (дети, взрослые, родители)
5. **Мои услуги** - 3 пакета услуг с описанием
6. **Стоимость** - Pricing карточки
7. **FAQ** - Часто задаваемые вопросы
8. **Контакты** - Форма связи и контакты
9. **Footer** - Подвал с ссылками

## Настройка Telegram Bot

Сайт интегрирован с Telegram Bot для автоматического получения заявок.

### Шаги настройки:

1. **Создайте .env файл** в корне проекта:
```env
VITE_TELEGRAM_BOT_TOKEN=your_bot_token_here
VITE_TELEGRAM_CHAT_ID=your_chat_id_here
```

2. **Получите токен бота:**
   - Напишите [@BotFather](https://t.me/BotFather) в Telegram
   - Создайте нового бота: `/newbot`
   - Скопируйте токен

3. **Получите Chat ID:**
   - Добавьте бота в группу/канал
   - Отправьте сообщение в чат
   - Перейдите: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Найдите `chat.id` в ответе

⚠️ **Безопасность:** Файл `.env` добавлен в `.gitignore` и не коммитится!

## Дизайн системы

### Шрифты
- **Основной текст:** Inter - современный, очень читаемый sans-serif
- **Заголовки:** Poppins - округлый, дружелюбный шрифт для акцентов

### Иконки
- **Библиотека:** [Phosphor Icons](https://phosphoricons.com)
- Современные, согласованные иконки с различными весами
- Легкие и читаемые

### Цветовая схема

**Контрастная пастельная палитра:**
- Primary: `#8B7AB8` (Мягкий фиолетовый) - успокаивающий, профессиональный
- Secondary: `#E5A491` (Теплый персиковый) - дружелюбный, приветливый
- Accent: `#7AB8B8` (Спокойный бирюзовый) - свежий, доверительный

**Дополнительные пастельные оттенки для фонов:**
- Lavender: `#E8E1F0`
- Peach: `#F5E6E1`
- Mint: `#E1F0F0`
- Cream: `#F5F0E8`
- Sky: `#E1EAF5`

Дизайн сочетает хороший контраст для читаемости с мягкими пастельными тонами для создания спокойной, доверительной атмосферы.
