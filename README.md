# Лендинг Юлии Поповой

Современный одностраничный лендинг для психолога, тьютора и профориентолога Юлии Поповой.

## Технологии

- React 18
- Vite
- Tailwind CSS
- Phosphor Icons

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр production сборки
npm run preview
```

## Структура проекта

- `/src/App.jsx` - Основной компонент со всеми секциями
- `/src/index.css` - Глобальные стили и Tailwind
- `/src/main.jsx` - Точка входа React
- `/index.html` - HTML-шаблон

1. **Header** - Навигация с плавным скроллом

8. **Контакты** - Форма связи и контакты
9. **Footer** - Подвал с ссылками

## Настройка Telegram Bot

Сайт интегрирован с Telegram Bot для автоматического получения заявок.

### Шаги настройки:

1. **Создайте .env файл** в корне проекта:
```env
VITE_TELEGRAM_BOT_TOKEN=your_bot_token_here
VITE_TELEGRAM_CHAT_ID=your_chat_id_here
```

2. **Получите токен бота:**
   - Напишите [@BotFather](https://t.me/BotFather) в Telegram
   - Создайте нового бота: `/newbot`
   - Скопируйте токен

3. **Получите Chat ID:**
   - Добавьте бота в группу/канал
   - Отправьте сообщение в чат
   - Перейдите: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Найдите `chat.id` в ответе

⚠️ **Безопасность:** Файл `.env` добавлен в `.gitignore` и не коммитится!

## Дизайн системы

Дизайн создан на основе лучших практик для психологов и wellness-индустрии:
- Профессиональная, но теплая атмосфера
- Высокая читаемость и доступность
- Современный минималистичный стиль
- Фокус на доверии и спокойствии

### Шрифты
- **Системные шрифты** для максимальной читаемости
- **Основной текст:** San Francisco (macOS), Segoe UI (Windows), Roboto (Android)
- **Оптимизированная типографика:** увеличенный line-height (1.7) для лучшей читаемости
- **Letter spacing:** -0.02em для заголовков (современный стиль)

### Иконки
- **Библиотека:** [Phosphor Icons](https://phosphoricons.com)
- Современные, согласованные иконки с различными весами
- Легкие и читаемые

### Цветовая схема

**Современная профессиональная палитра:**

- **Primary:** `#5B4B8A` (Глубокий фиолетовый)
  - Символизирует: мудрость, профессионализм, доверие
  - Используется для: header, hero, основные акценты

- **Secondary:** `#D88A6F` (Теплый терракотовый)
  - Символизирует: тепло, дружелюбие, поддержку
  - Используется для: вторичные элементы, карточки услуг

- **Accent:** `#6B9B7A` (Спокойный зеленый)
  - Символизирует: рост, гармония, баланс
  - Используется для: call-to-action, badges

**Нейтральные оттенки:**
- Полная палитра от 50 до 900 для идеального контраста
- Обеспечивает читаемость текста на всех фонах

### Hero секция

- Круглым placeholder для аватара (320x320px на десктопе)
