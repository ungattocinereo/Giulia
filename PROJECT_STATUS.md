## Границы проверки и содержимое

Полная реальная доставка заявки в канал не проверялась: тестового сообщения не отправляли. Перед публикацией нужна одна согласованная контрольная заявка через рабочий домен.

Текущий публичный ключ reCAPTCHA не разрешает `localhost` (подтверждено в браузере). Локальный просмотр и автоматические тесты работают; для реальной локальной отправки через сервер нужно отдельно разрешить соответствующий домен в настройках ключа. Локальный прокси по умолчанию выключен.
